# TSI Launcher: Bedrock Edition

## Product boundary

TSI is a version-channel catalogue and launcher for the official Minecraft Android package. It does not mirror, re-sign, patch, or redistribute Mojang/Microsoft game APKs or assets. Android install/update and package signing remain under Google Play / the official Minecraft distribution channel. A Microsoft account or Google Play entitlement is not generated by TSI.

Bedrock Android does not expose a public Java-style snapshot archive. The catalogue therefore lists only official stable, Preview and beta entry points. Historical/sideload APK archives are deliberately not presented as official downloads.

## Architecture

- UI: Jetpack Compose Material 3. The Bedrock catalogue uses LazyColumn (the Compose-native virtualized scrolling list; the RecyclerView equivalent), FilterChip categories, search text from the launcher top bar, status badge, size/source metadata and action buttons.
- State: Compose state in BedrockDashboard; selected channel and catalogue list are kept in the screen state.
- Data: BedrockVersionCatalog fetches JSON over HTTPS from bedrock/versions.json. The parser validates required fields and permits only official Google Play / Minecraft HTTPS hosts. Built-in official links are used if the catalogue is unavailable.
- Installed game: BedrockIntegration inspects com.mojang.minecraftpe and launches the installed official app.
- Install/update: action buttons open the relevant official Play listing or beta enrollment page. Play Store performs download, signature verification, install, update and entitlement checks.
- Background work: catalogue retrieval runs on Dispatchers.IO. Game binary downloads are intentionally not implemented because TSI does not host or redistribute proprietary signed packages. Therefore no fake download progress or misleading APK installer is shown.

## JSON schema

Each entry has:

| Field | Type | Meaning |
|---|---|---|
| id | string | Stable unique key |
| name | string | Display title |
| channel | string | vanilla, preview, beta |
| badge | string | Short release badge |
| versionLabel | string | Human-readable official channel/version |
| sizeLabel | string | Size/source information; Play Store controls actual package size |
| description | string | Short explanation |
| actionLabel | string | Button text |
| actionUrl | HTTPS URL | Must be on play.google.com or www.minecraft.net |
| enabled | boolean | Whether the official link is active |

The parser rejects URLs outside the official host allowlist. Do not add arbitrary APK mirrors.

## Future production work

1. Replace the static JSON file with a controlled HTTPS catalogue service and signed catalogue documents.
2. Add schema version, publishedAt, ETag/If-None-Match and cache expiry.
3. Add automated JSON schema validation in CI and unit tests for invalid URLs, unknown channels and missing IDs.
4. Add Play Store availability checks for Preview without assuming all regions/devices are eligible.
5. Add explicit user confirmation before opening external store pages and retain a visible source label.
6. Keep Java snapshots separate from Bedrock channels. Bedrock's official Android beta/preview availability is controlled by Mojang and Play.

## Current implementation

The Bedrock tab includes a remote catalogue, local fallback, All/Vanilla/Preview/Beta filters, search, installed-package detection, Play launch and official store actions. It does not claim that old Bedrock APK versions can be downloaded directly.
